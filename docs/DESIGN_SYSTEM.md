# Дизайн-система ArcForChrome

## Из чего собирать интерфейс

| Задача | Где брать |
| --- | --- |
| Цвет, шрифт, отступ, радиус, размер иконки | `extension/design-tokens.css`. Используйте переменные `--arc-*` по их назначению |
| Страница настроек или журнала | `extension/page.css`. Заголовок страницы, секции, поля, кнопки, основное действие и ряд действий уже оформлены |
| Строка результата или команда | `extension/palette.js`. Используйте существующую строку, тип результата, подпись действия и контекстное меню |
| Значок действия | `iconPaths` и `resultIcons` в `extension/palette.js`. Контур 24 × 24, единая толщина штриха, скруглённые концы и цвет текста |
| Значок сайта | Локальный кеш Chrome с контурным запасным значком. Используется только у результатов, представляющих страницы |
| Значок приложения | Локальные PNG в `extension/icons/` |

## Компоновка

В панели сверху находится поле запроса, под ним результаты, снизу основное
действие и кнопка Actions. Заголовок строки отвечает за распознавание
результата, подстрочник показывает адрес или полезный контекст. Справа
достаточно одной метки источника либо названия группы.

Новое действие, относящееся к выбранной строке, добавляйте в Actions.
Самостоятельное действие с собственным запросом помещайте в каталог команд.
Используйте отдельный режим, когда пользователю нужно заполнить форму,
выбрать папку или отфильтровать провайдеров.

Для нового элемента проверьте светлую, тёмную и контрастную темы, узкое окно,
увеличенный системный шрифт и управление с клавиатуры. У интерактивных
элементов должен быть видимый фокус и доступное имя. Строка результата
должна оставаться понятной, даже если справа скрылась метка источника.

## Как подключается оформление

Страницы расширения подключают CSS из своей папки. Панель поверх сайта
работает в изолированном iframe и Shadow DOM. Её функция передаётся Chrome
для внедрения, поэтому токены читаются из того же локального файла и
передаются вместе с параметрами панели. Внешних шрифтов и библиотек
иконок интерфейс не загружает.
