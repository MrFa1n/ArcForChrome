Automatic cleanup

Text recording is off by default. AI recovery copies are separate and temporary. Text already recorded stays until it expires or is cleared.

Learning is on by default when action recording is enabled. Spotlight keeps the selected command or AI provider, command position, and topic vectors in this local history. The text setting controls whether the original query is kept. Disabling learning pauses it. Clearing history also resets learned preferences.

168 hours = 7 days. Use 0 for no age limit; the entry limit still applies. Cleanup runs automatically while Chrome is running.
