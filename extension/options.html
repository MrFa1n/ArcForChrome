Arc Search

Search settings

Default search engine

Web queries use the search engine selected in Chrome.

Site Search

Type a keyword such as yt, press Tab, then enter your query. Use %s once in each search URL for the query.

Keyboard

⌘T opens search. ⌘L opens the current URL for editing. Existing Chrome assignments may be preserved after updates.

Inside search: empty Tab opens Commands; a site keyword + Tab enters Site Search; Tab on a URL completes it. Enter opens, Shift+Enter opens in background, Alt+Enter replaces the current page. In Edit mode, Enter replaces the current page; ⌘/Ctrl+Enter opens a new tab.
