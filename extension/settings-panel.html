Interface language

Choose a language. Reopen Spotlight or refresh open extension pages to use it everywhere.

Default search engine

Web queries use the search engine selected in Chrome.

Search shortcuts

Google, Yandex, ChatGPT, Google AI Mode (gem/gemini), Claude, Grok and Perplexity are ready to use. Type a shortcut followed by your query (for example, gem explain closures) and press Enter. Other sites are detected locally from search URLs in tabs, bookmarks and history. Shortcut + Tab also works.

    Optional manual overrides

    Set a keyword and type keyword + query, or press Tab after the keyword. Use %s once in each search URL for the query.

    Spotlight preferences

    Learning uses local activity history to improve suggestions.

    Activity history

    Review Spotlight actions, set retention/count limits, disable recording or clear history. Query text is excluded by default.

    Keyboard

    ⌘T opens search. ⌘L opens the current URL for editing. Existing Chrome assignments may be preserved after updates.

    Inside Spotlight

    Choose a shortcut field and press Ctrl or ⌘ with a letter or number. Shift and Alt are optional.

    Inside search: empty Tab opens Commands; a site keyword + Tab enters Site Search; Tab on a URL completes it. Enter opens, Shift+Enter opens in background, Alt+Enter replaces the current page. In Edit mode, Enter replaces the current page; ⌘/Ctrl+Enter opens a new tab.
